WGMMA

CuTe学习8-SM90 WGMMA

WGMMA WGMMA（Warp-Group Matrix Multiply-Accumulate）是NVIDIA Hopper引入的Tensor Core指令族。它把参与一次矩阵乘加的协作单位从一个 Warp 扩展为一个 Warp Group。 SM90_64x64x16_F16F16F16_SS 我们先观察一条指令及其在 CuTe 中的封装： 1SM90_64x64x16_F16F16F16_SS 2wgmma.mma_async.sync.aligned.m64n64k16.f16.f16.f16 m64n64k16 表示本条指令覆盖 64x64x16 的 MMA tile。 SS 表示 A、B 都通过 64-bit shared-memory descriptor 访问，直接从Shared Memory中取数。CuTe也封装了 RS 等形态，允许其中一个操作数来自寄存器。 mma_async 表示指令提交到异步队列，指令发射后即退休。 sync.aligned 仍然要求整个 128-thread warp group 在相同控制流位置、以相同参数发射指令。async 不等于四个 Warp 可以各自独立调用。 WGMMA新特性主要在支持更大的矩阵形状、从 Shared Memory 直接读取操作数，以及异步发射和完成通知。 Warp Group 与更大的 Tile Ampere 的 mma.sync 通常以一个 Warp 为协作单位，FP16 常见的单条指令形状是 m16n8k16。如果要计算更大的输出 tile，就需要排列很多条 MMA，并在指令之间安排寄存器搬运和同步。Hopper 的 WGMMA 由 128 个线程共同完成，一条指令可以覆盖 m64n64k16 到 m64n256k16 等更宽的输出形状，减少了指令和元数据开销。 ...
